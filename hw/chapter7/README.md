# Chapter 7 作业：CPU 调度（OSTEP）

这次作业我用 `scheduler.py` 模拟了 FIFO、SJF 和 RR 三种调度策略，比较了它们的平均响应时间、平均周转时间和平均等待时间。

- 每道题的预测、理由、验证结果和分析：`analysis.md`
- 模拟器的原始输出：`data/`

## 我的发现

1. **作业按从短到长到达时，SJF 和 FIFO 的结果完全一样。** 作业长度为 200、200、200 和 100、200、300 时，两者的平均响应时间分别是 200.00 和 133.33，平均周转时间分别是 400.00 和 333.33，没有任何区别。
2. **RR 的响应时间最好，但周转时间最差。** 作业为 100、200、300 时，RR（时间片 1）的平均响应时间只有 1.00，FIFO 和 SJF 是 133.33；但平均周转时间是 465.67，比 FIFO 和 SJF 的 333.33 差很多。原因是 RR 让所有作业轮流往前推进，大家都拖到接近最后才完成。
3. **SJF 的响应时间随作业变长而线性变差。** 作业长度从 100、200、300 依次放大到 200、400、600，300、600、900 和 400、800、1200，平均响应时间依次是 133.33、266.67、400.00、533.33，每次增加 133.33。
4. **RR 的时间片越大，响应时间越差，周转时间反而越好。** 三个长度为 100 的作业，时间片从 1 增加到 100，平均响应时间从 1.00 变成 100.00（正好等于时间片），平均周转时间从 299.00 降到 200.00。时间片等于作业长度时，RR 的结果和 FIFO 一样。N 个作业的最坏响应时间是 (N − 1) × 时间片。
